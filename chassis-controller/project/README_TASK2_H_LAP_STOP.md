# H题 Task2：环线一圈并停回 A 点

本文说明当前菜单 `Task2` 的功能、操作和实车标定方法。它对应赛题要求：

- 小车置于 A 点；
- 按键启动后沿黑线顺时针行驶一圈；
- 返回 A 点后自动停车并显示总用时；
- 目标为总时间不超过 20 s、停车偏差不超过 2 cm。

## 1. 与 Task9 的关系

Task2 复用 Task9 已验证中的 H 题直线/0.5 m 半径圆弧统一循迹算法，包括趋势
前瞻、弯道降速和自适应差速。两者的停车行为严格分离：

- Task2：计时、末段减速、识别 A 点启停线并自动停车；
- Task9：继续作为持续环线调试模式，只能由 KEY4、低压保护或其他安全保护停止。

因此可先用 Task9 调整纯循迹，再用 Task2 调整一圈停车，不会失去原对照入口。

## 2. 操作方法

1. 将小车指定测试位置对准 A 点停车基准线。
2. 车头朝 A→B 方向，使车辆沿赛道顺时针行驶。
3. OLED 选择 `2:H Lap Stop`。
4. 短按 KEY4 发车；计时从本次启动状态初始化后开始。
5. 运行中短按 KEY4 可紧急停止。
6. 自动停车后 OLED 显示 `[DONE]` 和冻结的总用时；再次短按 KEY4 可重新开始。
7. KEY3 可切换到 ADC/陀螺仪调试页。

## 3. 停车状态机

控制周期为 5 ms：

1. 发车时记录当前累计偏航角、清零计时和宽线检测状态。
2. 起点阶段必须先连续 50 ms 离开宽线，且发车至少 1 s，避免把起点误判为终点。
3. 累计偏航变化未达到约 300°前，只循迹、不接受终点宽线。
4. 达到约 300°后，基础速度降为 20，并开始接受 A 点宽线。
5. 宽线需要连续 15 ms 满足左右两侧均有探头、有效探头数和总信号阈值。
6. 确认宽线后按 `StopDly` 继续循迹指定时间，然后同时关闭左右电机、冻结时间并鸣笛。

300°只是终点检测的布防角，不是停车角；实际停车依据仍是 A 点 5 cm 黑色启停线。

## 4. 可调参数

OLED 参数页提供：

- `StopDly`：0~500 ms，步长 5 ms。用于补偿循迹探头与车体指定测试位置之间的
  前后距离，以及少量停车惯性。初次测试从 0 ms 开始。

实车观察确认 A 点横向黑线由 CH3、CH4、CH5 覆盖，因此停车判断改为三路
归一化 ADC 值求和：

- `h_stop_ch345_sum_threshold = 240`：CH3+CH4+CH5 的临时最小和值；
- `h_stop_ch345_sum`：当前三路和值，范围为 0~300。

OLED Task2 页面显示 `CH345` 当前和值和 `Thr` 阈值。240 是避免普通纵向线
只覆盖一至两路时误触发的保守初值，仍需比较普通线最大值与 A 点横线最小值后
重新标定。

## 5. 推荐实车验证顺序

1. 架空车轮，确认待机和 KEY4 停止时两路 PWM 均为 0。
2. 使用 Task9 验证整圈循迹不会脱线。
3. 低速运行 Task2，记录普通线与 A 点宽线的 `CH345`。
4. 调整 `h_stop_ch345_sum_threshold`，要求它高于普通线最大值、低于
   A 点横线最小值。
5. 从 `StopDly=0` 开始，每次增加 5~10 ms，测量车体指定测试位置到基准线的偏差。
6. 重复至少 5 次，确认不会起步误停、弯道误停或漏停。
7. 最后逐步提高速度，在保持停车偏差不超过 2 cm 的前提下验证总时间不超过 20 s。

## 6. 当前验证边界

- Keil 完整构建应保持 0 error / 0 warning。
- 软件已具备计时、末段布防、宽线确认、停车延时和物理停机链路。
- 20 s 和 2 cm 是实车指标，必须完成上述标定与重复测试后才能确认达标。
